Why you would want it

Concrete reasons — not vaporware.

1. Continuity

When jobs, titles, or projects end, your people and promises don’t. The app keeps that thread.

2. Privacy

Hard conversations about family and purpose don’t need a SaaS training pipeline by default.

3. Low ceremony

One command. Empty states are screens inside the app — not a wall of CLI recipes.

4. Honest roles

No romantic AI. No fake consciousness claims. Partner integrity is part of the design.

5. Builder hygiene

If you still ship code with agents, Rails can block dumb paths and show real end-of-run numbers.

6. You own it

MIT, Python, local files. Fork it, thin it, or run it offline once models are on disk.

Start in one minute

Apple Silicon recommended. Python 3.11+.

cd MLX-SAGE python -m venv .venv && source .venv/bin/activate pip install -e ".[tui]" export PYTHONPATH=. nex

Need a model? The app tells you. Or: nex models recommend "chat" --max-memory 16 then download and press F5 in the app.
